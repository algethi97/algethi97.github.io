## 사람
### 목표
홈페이지 5개 페이지 전체를 리모델링하기 전에 세 방향의 HTML 시안을 만듭니다. 세 방향은 A 데스크테리어 개선안, B 에디토리얼안, C 터미널안입니다. TAEKONG님은 실제 브라우저에서 세 시안을 비교해 보고 콘셉트를 확정합니다. 시안마다 홈 화면, 포트폴리오 화면, 새 데스크테리어 배경 이미지를 만듭니다. 모니터 확대 연출과 한국어 중심 문구는 유지합니다.

### 결정과 이유
- D1 배경 이미지 제작 방식은 A로 정했습니다. 배경은 SVG 일러스트로 직접 그리고, 같은 장면을 다시 만들 수 있도록 한국어·영어 이미지 생성 프롬프트(`bg-prompt.md`)를 함께 남깁니다. 실행 AI는 사진 같은 이미지를 만들 수 없습니다. 그래서 먼저 SVG로 구도와 색을 비교하고, 고품질 이미지는 나중에 프롬프트로 다시 만들 수 있게 했습니다.
- D2 시안 폴더 위치는 A로 정했습니다. 시안은 `design/mockups/`에 둡니다. 이 폴더를 커밋하고 푸시하면 `https://algethi97.github.io/design/mockups/`로 공개됩니다. 커밋은 TAEKONG님이 요청하실 때만 합니다.
- 귤은 디자인의 대표 캐릭터로 쓰지 않습니다. 지금 사이트처럼 🍊 이모지와 만다린 게임 설명에만 남깁니다. TAEKONG님이 "귤 유지"는 메인 캐릭터로 삼으라는 뜻이 아니라고 정정해 주셨기 때문입니다.
- 확대 중심 위치는 지금 사이트에 실제로 적용된 값인 41.5%를 씁니다. 계획서에 처음 적었던 43.62%는 코드 주석에서 옮긴 값이었고, 실제 적용값과 달랐습니다.
- 이메일은 지금 사이트처럼 누르면 주소가 복사되는 버튼으로 유지합니다.
- A 시안 배경의 귤 피규어 자리에는 기존 배경처럼 책 더미를 놓습니다. A 시안을 고르면 어차피 귤을 지워야 하므로, 비교 단계에서 미리 맞춰 둡니다.

### 현재 작업

## AI
4단계 비교 페이지와 스크린샷 정리를 완료했습니다. A의 귤 그림을 하드커버 책 3권으로 바꾸고 중심축을 49.91%·41.5%로 보정했으며 이메일 복사와 안내 토스트를 적용했습니다. design/mockups/index.html에 세 방향의 특징·색 견본·홈과 포트폴리오 링크 6개·대표 이미지 6개·비교표를 추가했습니다. capture.mjs로 18장을 생성했고 모든 화면에서 가로 넘침이 없었습니다. Chrome 동작 검사, 회귀 테스트 9개, 구문 검사와 동봉 검증이 통과했습니다. 리모델링 변경량은 가설/임시 예상으로 표시했습니다. 시안을 커밋하고 푸시하면 공개됩니다.
