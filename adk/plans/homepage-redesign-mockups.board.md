## 사람
### 목표
홈페이지 5개 페이지 전체를 리모델링하기 전에 세 가지 방향의 HTML 시안을 만듭니다. 세 방향은 A 데스크테리어 개선안, B 에디토리얼안, C 터미널안입니다. TAEKONG님은 시안을 실제 브라우저에서 비교해 보고 콘셉트를 확정합니다. 시안마다 홈 화면, 포트폴리오 화면, 새 데스크테리어 배경 이미지를 만듭니다. 모니터 확대 연출, 한국어 중심 문구, 귤 캐릭터는 유지합니다.

### 결정과 이유
- D1 배경 이미지 제작 방식은 A로 정했습니다. 배경은 SVG 일러스트로 직접 그리고, 시안마다 한국어·영어 이미지 생성 프롬프트(`bg-prompt.md`)를 함께 남깁니다. 실행 AI는 사진 같은 이미지를 만들 수 없습니다. 그래서 구도와 색은 SVG로 먼저 비교하고, 나중에 프롬프트로 고품질 이미지를 다시 만들 수 있게 했습니다.
- D2 시안 폴더 위치는 A로 정했습니다. 시안은 `design/mockups/`에 둡니다. 이 폴더는 리모델링 단계에서 참고하기 쉽습니다. 다만 커밋하고 푸시하면 `https://algethi97.github.io/design/mockups/`로 공개됩니다. 커밋은 TAEKONG님이 요청하실 때만 합니다.
- 귤 캐릭터는 사이트의 대표 캐릭터로 유지합니다. 시안마다 그 시안의 화풍에 맞게 다시 그려 배경과 홈 화면에 넣습니다.

### 현재 작업
단계 1. 방향 A 데스크테리어 개선안 시안 · 완료

## AI
단계 1을 완료했습니다. 방향 A의 다섯 시안 파일과 맵을 추가했습니다. 1440×900·390×844에서 홈 축소·확대·포트폴리오 여섯 화면을 확인했으며 가로 넘침과 모니터 경계 검사가 통과했습니다. 클릭·Enter 확대, ESC·축소 버튼 복귀, 본문 스크롤과 기존 회귀 테스트 9개도 통과했습니다. 임시 캡처와 결과는 .scratch/mockup-a/에 있습니다. 진행 기록은 sequence 3, reported입니다.
